With:

```javascript
function appendMessage(content, type) {
  const div = document.createElement('div');
  div.className = type;
  if (type === 'server') {
    // Server messages are trusted — render as Markdown (per D-02)
    div.innerHTML = marked.parse(content);
  } else {
    // User messages remain plain text (XSS safe)
    div.textContent = content;
  }
  messages.appendChild(div);
  messages.scrollTop = messages.scrollHeight;
}
```

This implements D-02: server messages use innerHTML with marked.parse(), user messages use textContent.
